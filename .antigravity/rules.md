# nikitastrike Portfolio

## 🎨 Global Design Guidelines
- **Strictly NO Glassmorphism**: Unless explicitly requested by the user, avoid background-blur, frosted glass effects, or excessive transparencies.
- **Architectural Aesthetic**: Prioritize structure, grid lines, and sharp edges (0px to 4px radius max). 
- **Typography Priority**: Use `Space Mono` for technical data, hashes, and code snippets. Use `Space Grotesk` ONLY for main headings.
- **Color Discipline**: Avoid lush gradients or vibrant color palettes. Use solid colors (Black/Slate-950/Charcoal) with the primary blue `#144bb8` as a structural accent (borders, small badges).
- **Industrial Layout**: Prefer "Split views", "Sidebars", and "Grid-based data" over centered simple layouts.
- **Information Density**: Systems Architect brand; prioritize clarity over "wow" marketing visuals.

## 🛠️ Implementation Rules
- **TypeScript First**: Ensure strict typing for all components.
- **Tailwind Configuration**: Use existing utility colors (`primary`, `background-dark`, `bone`, `charcoal`). 
- **Component Style**: Keep components focused, atomic, and reuse the established "Border-Symmetric" look.
